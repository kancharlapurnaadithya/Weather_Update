# India Weather Update Application

A clean, basic, and accurate real-time Weather Update Application built exclusively using standard **HTML5**, **CSS3**, and **JavaScript** (Fetch API).

---

## Features

1. **No API Key Required**:
   - Works immediately out of the box with zero setup.

2. **Accurate Indian State & City Weather**:
   - Comprehensive coordinates database covering all 28 States and 8 Union Territories of India (Andhra Pradesh, Telangana, Maharashtra, Karnataka, Tamil Nadu, Delhi, Gujarat, etc.).
   - Simple **Select State / City** dropdown for quick one-click weather checks.
   - Smart search bar to type any Indian city or town name.

3. **Current Weather Information in Indian Standard Time (IST)**:
   - City and state name (e.g. `Hyderabad, Telangana` or `Vijayawada, Andhra Pradesh`).
   - Current temperature in Celsius (°C).
   - Weather condition (Clear Sky, Haze, Clouds, Rain, Thunderstorm).
   - Official weather icon.
   - Feels-like temperature (°C).
   - Minimum and Maximum temperatures (°C).
   - Relative humidity (%) and Wind speed (m/s).
   - Live Indian Standard Time (IST) clock.

4. **GPS Geolocation**:
   - One-click **My Location** button detects local weather using browser geolocation.
